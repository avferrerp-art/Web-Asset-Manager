════════ CONTEXTO DEL PROYECTO ════════

LogiFleet es un sistema de gestión logística de flota. Importa ventas desde Odoo,
planifica despachos (vehículo + chofer + ruta), calcula costos, y tiene una app
móvil para choferes.

  lib/db/               Drizzle: schema (fuente de verdad) + migraciones embebidas

  lib/api-client-react/ GENERADO desde el spec (hooks React Query) — NO editar
  artifacts/api-server/ API Express 5
  artifacts/logistics/  Web React + Vite
  e2e/                  Vitest (API) + Playwright (UI)

════════ POR QUÉ ESTA TAREA ════════

Estamos integrando traslados internos entre almacenes. La tarea anterior agregó
`products.pesoKgOdoo` y `products.volumenM3Odoo` (nullable, con mapeo `<=0 → null`)
sin advertir que la tabla YA tenía `products.pesoOdoo` y `products.volumenOdoo`,
sincronizados desde los mismos campos de Odoo (`weight` y `volume`) pero usando 0
como centinela de "sin dato".

Resultado: cuatro columnas para dos hechos. Antes de que la lógica de traslados
agregue lecturas nuevas hay que dejar una sola verdad.

Esta tarea NO agrega funcionalidad. Es consolidación.
